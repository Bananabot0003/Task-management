# Python Task Management System

## About the Project

This is a simple Task Management System I created using Python for my programming class. The program allows users to add tasks, mark tasks as complete, view pending tasks, and track their progress.

The goal of this project was to practice using Python functions, loops, dictionaries, modules, and input validation.

## Features

- Add new tasks with a title, description, and due date
- Mark tasks as completed
- View tasks that still need to be done
- Track the percentage of completed tasks
- Check user input to help prevent errors

## Project Files

- `main.py` - Runs the program and displays the menu
- `task_manager/task_utils.py` - Handles adding, completing, and viewing tasks
- `task_manager/validation.py` - Checks user input for errors

## How to Run

Make sure Python 3 is installed on your computer.

Open the terminal in the project folder and run:

```bash
python3 main.py
```

Follow the menu options to manage your tasks.
